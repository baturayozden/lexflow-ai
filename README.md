# LexFlow

AI automation systems for UK immigration and conveyancing law firms.

## What's in this repo

- `site/index.html` — Landing page (Tailwind CSS via CDN, no build step required)

## Running locally

Open `site/index.html` directly in a browser, or serve with any static server:

```bash
npx serve site
```

## Stack

- HTML5
- Tailwind CSS (CDN)
- Inter font (Google Fonts)
- Vanilla JavaScript
